## Where we are

The current best VLM is **C1 class-only four-way**:

- Base: Qwen3-VL-8B-Instruct
- Inputs: close candidate image + wider context image
- Output: `radar`, `missile`, `other`, or `background`
- Training: 1,764 unique examples, two epochs
- LoRA: language layers + vision-language merger
- Vision encoder blocks: frozen
- No CoT required for C1

## What happened recently

1. **R1 CoT four-class model failed on detector boxes.**  
    Its `other/background` explanations lacked diversity, and it continued predicting mostly radar/missile. That evaluation was intentionally stopped at 2,473/6,983 boxes.

2. **Visual-grounding investigation completed sufficiently.**  
    The 40-example intervention study and 72/72 early-prefix follow-up showed that both images can influence predictions, but generated text can strongly anchor later reasoning. This did not prove that every explanation is visually faithful.

3. **C1 class-only training worked much better.**

| Evaluation                          | Macro-F1 | Radar P/R/F1   | Missile P/R/F1 |
| ----------------------------------- | -------- | -------------- | -------------- |
| Balanced 256-box diagnostic         | 0.553    | .694/.531/.602 | .567/.797/.662 |
| Natural clean67, 4,231 Stage1 boxes | 0.410    | .196/.568/.292 | .249/.585/.349 |
4. **C1 versus YOLO comparison completed.**  
    On 387 clean radar/missile GT instances:

| Outcome           | Instances |     |
| ----------------- | --------- | --- |
| Both correct      | 138       |     |
| VLM only correct  | 30        |     |
| YOLO only correct | 66        |     |
| Both wrong/missed | 153       |     |
5. **Low-confidence Stage1 audit found a useful clue.**  
	Two radar boxes excluded by the confidence-0.50 gate, `18r01` and `1Br01`, were correctly classified by C1 when manually forwarded. This suggests lowering the detector gate might recover targets, but we have not measured the additional false-positive cost.


## What we should do next

1. **First priority: fair hand-off evaluation.**  
    Run fixed C1 on the current Stage2/Test116 candidate boxes and/or a pre-registered lower Stage1 confidence threshold. Measure recovered radar/missile instances and additional false proposals together.
    
2. **Then test an actual fusion/re-checker rule.**  
    Combine YOLO and C1 while counting precision, recall, F1, duplicate predictions and routing conflicts. The existing oracle union is only a theoretical recall ceiling.
    
3. **Only then decide about retraining.**  
    If classification/rejection remains the bottleneck, prepare Train-only hard negatives and retrain C1. First inspect final image pixels and prompts for label leakage.
    
4. **Secondary task: finish the paper studies.**  
    Paper 1 is explicitly unfinished; Paper 2 has partial LOOK/PERCEIVE/UNDERSTAND notes. Neither has yet become a controlled experiment.
