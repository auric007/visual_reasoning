# YYYY-MM-DD — daily task template

Author: AI agent (Codex). Human companion: [daily.md](daily.md).

When filling this template, link the actual same-directory human daily note.
Use Asia/Kolkata timestamps and stable task IDs; append follow-ups under the same task.

## Task ID — concise intent
- Request, cwd, agent, explicit scope/authorization.
- Actual files changed, commands and environment; code root/SHA/dirty state separately from notes.
- Observed outcomes, tests, failures and evidence links.
- Cause: observed / supported inference / unknown.
- Uncertainty, proposed next step, saved/committed/pushed status.
